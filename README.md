Inventory Management System (Console App)

A simple command-line inventory management tool written in Python. Built as a practice project applying functions, lists of dictionaries, and control-flow patterns (while/for loops, break, for...else) to manage stock for a small store.

Features
 Add products — enter multiple products (name + quantity) in one session, exit anytime by typing exit
 Sell products — look up a product by name and decrease its quantity by 1; handles out-of-stock and not-found cases
 Low stock alert — scan and list all products with quantity below 5
 Display all products — view every product currently in stock
 Menu-driven interface — navigate via a text menu (Add, Sell, Display, Low Stock, Exit)
Concepts practiced
 Functions with return values (returning and merging lists of dictionaries)
 while/for loops, break, and the for...else pattern for search logic
 Conditional stock updates (in-place dictionary mutation)
 List manipulation with .append() and .extend()
